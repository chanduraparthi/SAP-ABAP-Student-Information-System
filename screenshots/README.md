## Screenshot rules

- Capture evidence from your own SAP session.
- Use synthetic student data only. Do not expose real names, email addresses or personal information.
- Do not use screenshots from another person's repository as evidence of this project's execution.
- If an image is a UI mockup rather than a real SAP output, label it clearly as a mockup.
- Add screenshots only after the relevant program or SAP object has been activated and tested.
