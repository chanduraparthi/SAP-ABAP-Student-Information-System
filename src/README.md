# ABAP source exports

Export the actual active source from SAP GUI and save it here using these filenames:

- `Z_STUDENT_MAJOR_PROG.abap`
- `Z_STUDENT_TOP.abap`
- `Z_STUDENT_SEL.abap`
- `Z_STUDENT_F01.abap`

These source files are intentionally not fabricated from partial screenshots or prior snippets. Add the exact exported source from the SAP system. Remove environment-specific credentials or secrets before committing.
